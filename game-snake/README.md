# Змейка

Минимальный HTML5 проект с игрой "Змейка" без сторонних библиотек.

## Управление
- **Клавиатура**: стрелки или WASD
- **Мобильные устройства**: экранные кнопки

## Особенности
- 🎮 Тёмная тема
- 📊 Счёт и рекорд (сохраняется в localStorage)
- ⚡ Ускорение змейки при наборе очков
- 📱 Адаптивный дизайн для мобильных устройств
